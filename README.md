# Quiz · 科学答题

面向课堂练习的小学科学在线答题项目，支持单人练习与同屏双人竞速。

## 首版范围

- 教科版（2024）小学科学四年级上册：空气、呼吸与消化、声音，共 24 课时。
- 按年级、册次和课时范围选择题目，支持多个课时组合。
- 单选题与判断题自动判分，统计答题数和正确率。
- 无需昵称；左右分屏双人限时竞速，答对加 1 分、答错不扣分，时间到按总分结算。
- 双人自动续题，进度和计时延续，重复题不重复计分。
- 适配电脑和 iPad，成绩保存在当前浏览器。
- 计划通过 GitHub Pages 发布项目主页。

在线体验入口：[mutiwangn.github.io/quiz](https://mutiwangn.github.io/quiz/)。这是用户要求的玩法体验构建，始终标注开发预览，使用少量原创样题；不连接题源。先保留默认课时并选择 5 题，即可体验单人与双人。它不代表正式实时版已通过整册验收。

学生页面呈现 Quiz 品牌，不显示具体题源名称和集成细节。前端使用 React + TypeScript + Vite，部署目标为 GitHub Pages；后台兼容 Workers。无学生账号，成绩保存于 IndexedDB。

## 本地运行

需要 Node.js 24。

```powershell
npm ci
npm run dev:api
```

另一个终端运行 `npm run dev`。默认地址为 `http://127.0.0.1:5173/quiz/`。

开发交互预览：打开 `http://127.0.0.1:5173/quiz/?preview=1`。预览使用明确标识的少量原创样题，默认“感受空气”和“空气能占据空间吗”，选择 5 题即可体验单人和双人；其他课时未提供完整样题。该查询参数只在 Vite 开发模式生效。普通生产构建不包含样题，也不回退使用样题；在线体验须单独执行 `npm run build:experience`。

真实模式需要配置 `.dev.vars`，见 [服务接入说明](docs/service.md)。支持页面提取适配器和规范化网关两种连接；不将任何一种称为已完成整册验收。登录信息仅保存在服务端，不提交仓库。
