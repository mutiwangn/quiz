# Quiz · 科学答题

面向课堂练习的小学科学在线答题项目，支持单人练习与同屏双人竞速。

## 首版范围

- 教科版（2024）小学科学四年级上册：空气、呼吸与消化、声音，共 24 课时。
- 按年级、册次和课时范围选择题目，支持多个课时组合。
- 单选题与判断题自动判分，统计答题数和正确率。
- 左右分屏双人限时竞速，按答对数结算。
- 适配电脑和 iPad，成绩保存在当前浏览器。
- 计划通过 GitHub Pages 发布项目主页。

## 项目状态

已实现选课、单人练习、同屏竞速、本机成绩、取题校验服务和整册发布检查。真实目录已经核验；完整题目与答案的实时接口仍待开通和适配，免费额度尚未确认。网站与后台尚未公开部署。

学生页面呈现 Quiz 品牌，不显示具体题源名称和集成细节。前端使用 React + TypeScript + Vite，部署目标为 GitHub Pages；后台兼容 Workers。无学生账号，成绩保存于 IndexedDB。

## 本地运行

需要 Node.js 24。

```powershell
npm ci
npm run dev:api
```

另一个终端运行 `npm run dev`。默认地址为 `http://127.0.0.1:5173/quiz/`。

开发交互预览：打开 `http://127.0.0.1:5173/quiz/?preview=1`。预览使用明确标识的少量原创样题，默认“感受空气”和“空气能占据空间吗”，选择 5 题即可体验单人和双人；其他课时未提供完整样题。该入口只在 Vite 开发模式生效，生产构建不包含样题，也不回退使用样题。

真实模式需要配置 `.dev.vars`，见 [服务接入说明](docs/service.md)。本仓库的规范化网关契约是待接入的内部接口，不是已验证的官方 API。

## 验证

```powershell
npm test
npm run typecheck
npm run test:e2e
npm run build
```

浏览器测试默认使用本机 Chrome；CI 使用 Playwright Chromium。测试涵盖 HTTP 题包检查、对局规则、跨单元选择、单人统计、双人独立进度、触控与本机成绩。

发布前执行真实整册检查，操作见 [发布说明](docs/release.md)。只有整册内容通过检查后才发布至项目主页。
