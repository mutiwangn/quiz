# 实时取题服务

## 当前状态

2024 年版整册目录已核验，三单元各 8 课时。页面提取适配器已实现，并核对登录后的课时筛选、两类标准答案和一题完整解析。列表存在缺字限制，故非零题号与答案标记不能证明正文完整。完整后台流程尚未通过真实验收；目前访问受限，本机已暂停取题，不能公开发布。

支持页面提取与规范化网关两种连接。`GATEWAY_URL` 是项目方的规范化网关契约，不是已验证的官方 API。页面提取使用负责人获准查看的页面和服务端登录状态；学生不需要源站账号。两种方式都需要独立验证权限、额度、完整题目和整册覆盖。

## 浏览器访问

| 接口 | 方法 | 内容 |
| --- | --- | --- |
| `/api/catalog` | GET | 教材、单元、课时目录 |
| `/api/batches` | POST | 当局实时题包与答案 |

请求格式：

```json
{ "catalogId": "book-id", "lessonIds": ["lesson-id"], "kinds": ["single", "boolean"], "count": 10, "excludeIds": ["already-used-id"] }
```

字段定义和运行时约束见 `shared/types.ts`、`shared/contracts.ts`。题干、选项、解析只使用纯文本；图像使用 HTTPS 地址与替代文字。题包须与目录和所选范围相符、题号与题干不重复、数量足够、标准答案指向唯一选项。不能可靠转成单选或判断的题目由适配器排除，不猜答案。界面采用 React 文本节点，禁止注入上游 HTML。

`excludeIds` 可省略，续题时包含本局已有题号，最多 1000 个。浏览器在剩余题量较少时准备下一批，配图加载完后追加到两侧共用题序；计时、得分和独立进度延续。重试遵守 `Retry-After`，到时丢弃迟到题包。

## 页面提取

- `SOURCE_SEARCH_ENDPOINT` 与 `SOURCE_SESSION_COOKIE` 只配置在服务端，不返回浏览器、不提交仓库。登录信息到期后由负责人正常重新登录。
- `SOURCE_ACCESS_BLOCKED=1` 在服务端阻止所有开局和续题，不发送题目请求。只有负责人处理访问限制并完成小样本核验后才恢复。
- 按已验证的课时路径和单选／判断类型请求列表。遵守响应声明的分页上限；每次准备最多 48 次源站读取，不能用翻页绕过权限。
- 明确标记缺字的列表只作为索引。只访问同一源站、正常可查看的完整详情页，核验主试题的标准答案区域，再提取题干、图片、选项与解析。完整详情受限即失败，不使用缺字内容，也不拼接多次残缺响应补字。
- 完整题目的内容生成稳定编号，避免源站每次变换展示题号导致旧题再次计分。重选相同题干也不能在同局重复得分。
- 判断题必须有明确对错；单选必须有唯一正确选项。复杂表格、无法可靠表达的公式或复合选项排除，不猜结构和答案。
- 检测到明确的账号锁定响应后，当前服务实例暂停后续取题；维护者须另设持久暂停配置，避免重启或其他实例继续请求。免费查看额度不能被普通 IP 限流替代。

开局或续题可能消耗免费详情查看次数。整册 48 项检查每项 5 题，可能消耗大量额度；须先验证少量完整题目、核对剩余次数与覆盖范围。尚未建立可靠的全局剩余额度接口，当前适配器不能承诺无人值守或长期免费。

## 规范化网关（待实际题源适配）

服务端配置 `GATEWAY_URL` 与 `GATEWAY_TOKEN` 后，Worker 发起：

- `GET <GATEWAY_URL>/catalog` → `Catalog`。
- `POST <GATEWAY_URL>/batches`，请求为 `BatchRequest` → `QuestionBatch`。
- 使用 `Authorization: Bearer <GATEWAY_TOKEN>`；拒绝重定向；单次请求最长 15 秒。
- 真实响应必须标记 `origin: "live"`。标记本身不能证明内容真实，接入验收仍须保留供应方返回与实际映射证据。
- 若单独配置 `CATALOG_ENDPOINT` 与 `CATALOG_BOOK_ID`，目录由公开目录适配器取得。网关必须使用与该目录相同的课时 ID；实际官方 ID 不同时由服务端明确转换。
- 网关每次接收开局请求都应调用获准使用的题源接口，遵守配额。不得用持久题库或预览回退伪装实时请求。

## 配置与免费额度

本地：复制 `.dev.vars.example` 为 `.dev.vars`，填写服务端配置。前端只允许 `VITE_API_BASE_URL`，不得写入题源密钥。

Workers：使用 `wrangler secret put` 保存 `SOURCE_SESSION_COOKIE` 或 `GATEWAY_TOKEN`；目录地址、目录册次 ID、搜索地址与网关地址也可作为 secret 配置，避免出现在公共仓库。`ALLOWED_ORIGIN` 为 `https://mutiwangn.github.io`。本机登录状态没有上传到任何云端；部署和云端网络行为尚未验证。

Worker 默认每个 IP 每分钟最多准备 12 次题目，CORS 只允许项目网页来源。CORS 不能阻止直接 HTTP 调用；IP 限流也不是全局日额度控制。公开部署前须依据实际免费额度建立全局额度控制；不自动付费。接口 429、401、403 都停止本次开局。

仅准备了 Workers 部署配置与本地 dry-run；尚未部署免费后台，也未验证大陆不同网络下的可达性、延迟和图片显示。是否可长期免费由实际供应方额度和托管条款决定。

## 错误

| HTTP | 代码 | 含义 |
| --- | --- | --- |
| 400 | `INVALID_REQUEST` / `INVALID_RANGE` | 设置或目录范围无效 |
| 429 | `RATE_LIMITED` | 本机网络请求过于频繁 |
| 503 | `SOURCE_NOT_CONFIGURED` | 尚无可用真实题源 |
| 503 | `ACCESS_REQUIRED` / `QUOTA_EXHAUSTED` | 权限或免费额度不可用 |
| 503 | `SOURCE_TEXT_INCOMPLETE` | 无法取得有明确答案的完整主试题 |
| 503 | `SOURCE_ACCOUNT_LOCKED` | 访问受限，已暂停取题，须维护者处理 |
| 422 | `INSUFFICIENT_QUESTIONS` | 所选范围可用新题不足 |
| 502 | `INVALID_UPSTREAM_DATA` / `UPSTREAM_UNAVAILABLE` | 返回内容未通过检查或外部服务失败 |
| 504 | `UPSTREAM_TIMEOUT` | 请求超时 |

失败响应不返回凭据、平台名称、原始页面或堆栈。前端保留所选范围，允许重试，题包和所有配图加载成功前不启动计时。
