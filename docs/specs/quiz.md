# Quiz implementation specification

## Problem Statement

教师希望按教材课时即刻开展科学练习与同屏双人竞速，减少手工维护题库，并自动获得作答统计。

## Solution

GitHub Pages 网页连接免费的实时取题后台，按课时取得并校验题包，支持单人、双人和本机成绩。真实内容未准备好时明确提示，公开发布前核实整册覆盖。

## User Stories

1. 教师可选择教材、年级、册次与任意课时组合。
2. 教师可选择单选、判断；单人选择题数，双人选择竞速时长。
3. 用户可看到准备状态，失败后保留范围并重试。
4. 无标准答案、错课时、重复、数量不足的题目不会悄悄进入对局。
5. 学生可逐题单人作答并看到解析及统计。
6. 两名学生无需昵称，固定左方／右方，在同设备左右区域独立作答同一题序。
7. 双人限时比较总分，答对加 1 分、答错不扣分，同分平局；首次有效提交计分。
8. 电脑可分别使用两组键盘按键；iPad 使用两侧触控按钮。
9. 到时停止作答，不因后台计时器节流而增加时长。
10. 双人做完当前题包不提前结算；自动续取新题并预加载配图，保留题序、独立进度、总分和原截止时间。重复题不再次计分。加载失败可重试，仍按原时间截止；放弃不结算、不保存成绩。
11. 单局总分、答题数、答对数、正确率与耗时保存到本机；旧记录用答对数兼容总分。
12. 用户可查看和清除本机成绩。
13. 对外页面只显示 Quiz 品牌与普通产品语言，不显示具体题源平台。
14. 项目维护者可配置服务端凭据，自动运行整册覆盖检查。
15. 接口未配置、数据受限或试用到期时显示可恢复的失败，不静默使用样题。
16. 开发者可在显式标识的本地预览模式验证所有交互。
17. 维护者可按用户要求单独发布明确标识的在线体验构建，用少量原创样题收集界面和玩法反馈；不连接题源，不作为正式实时版或整册发布。

## Implementation Decisions

- 首发教材为教科版（2024）四年级上册，空气、呼吸与消化、声音三单元共 24 课时。
- 前端采用 React、TypeScript、Vite；后台优先兼容免费 Workers 运行时。
- 使用统一的目录、题包和题目契约；来源适配器在真实返回得到验证后实现。
- 单选使用选项 ID，判断也规范为明确选项；题干、选项和解析与答案分离。
- 本局先校验题包和资源，再启动统一截止时间。
- 对局状态以首次提交为准；单人与双人复用同一对局规则。
- 成绩保存在 IndexedDB；存储失败不丢失当局结算，并向用户说明未保存。
- 开发预览与真实模式显式分离；未完成上游接入时真实模式失败关闭。
- UI 系统与题源调查分离，具体平台调查记录留在本地管理资料。
- 负责人可扫码登录后由服务端复用可访问的页面；只读取正常可见内容。列表标记缺字时只把它当索引，转到完整详情页校验题干、标准答案和解析；不拼接缺字响应恢复正文，不跨越分页和免费查看限制。
- 题源明确锁定时停止继续取题，维护者可通过服务端配置保持暂停。未完成整册真实验收不发布。

## Testing Decisions

用户已确认三个公开测试入口：

1. HTTP 取题服务：检查范围、答案、去重、数量、超时和错误；不代替教学内容审核。
2. 对局公开接口：检查首次提交、独立进度、时间边界、正确率和结算；不验证实际浏览器绘制。
3. 浏览器流程：检查选课、练习、对战、持久化和屏幕适配；仿真不替代真机课堂试用。

通过这些入口逐个 red-green 切片实现，不测试私有实现结构。外部网络、随机数和时间是允许控制的系统边界。

## Out of Scope

异地房间、随机匹配、学生云账号、跨设备同步、付费服务、填空或主观题。

## Further Notes

真实接口开通与整册覆盖是首次公开上线的必要条件。代码和本地预览可先供审阅，不提前发布一个内容覆盖不足的公开答题网站。
